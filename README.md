# 📦 Inventory Management System

A dynamic, full-stack warehouse inventory management application built for tracking technology and electronic gadget stock. Powered by Node.js, Express, PostgreSQL, and EJS, Pulse Tech provides full CRUD capabilities across categorized hardware, enabling warehouse operators to monitor stock levels, manage suppliers, and organize product catalogs efficiently.

[Live Link](https://inventory-application-2k50.onrender.com/)

---

## ✨ Features

* **Full Inventory CRUD Operations:** Create, read, update, and delete tech gadgets, hardware components, and warehouse categories in real time.
* **Relational Category Architecture:** Organize inventory items into structured departments (e.g., *Audio Gear*, *Computing*, *Peripherals*, *Smart Devices*) with relational foreign-key integrity.
* **Stock & Pricing Tracking:** Monitor unit pricing, available stock counts, and detailed hardware specifications across the entire catalog.
* **Form Validation & Error Handling:** Server-side input sanitization and validation using `express-validator` to ensure clean, reliable database entries.
* **Server-Side Rendered UI:** Clean, responsive, card-based interface rendered dynamically via EJS templates and styled with modern Vanilla CSS.
* **Persistent Cloud Storage:** Backed by a cloud PostgreSQL database (Neon) with secure SSL connection pooling.

---

## 🛠️ Tech Stack

* **Backend Runtime & Framework:** Node.js, Express.js (MVC Architecture)
* **Database:** PostgreSQL (`node-postgres` / `pg` connection pooling, Neon Cloud DB)
* **Templating & Frontend:** EJS (Embedded JavaScript), Vanilla CSS3 (Responsive grid & card layouts)
* **Validation & Environment:** `express-validator`, `dotenv`
* **Deployment:** Render (Web Service)
